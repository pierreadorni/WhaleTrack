# Whale Track - Telemetry-Driven Georeferenced Multi-Whale Tracking from Drone Video

*WhaleTrack*, is a modular system that combines oriented-bounding-box detection, multi-object tracking with lightweight spatial relinking, telemetry-driven ray–plane reprojection from drone GPS, altitude, and gimbal orientation, and per-frame field-of-view estimation.

This repository contains the code accompagnying a paper presented at the 2nd Workshop on Marine Vision in conjunction with the *19th European Conference on Computer Vision* -- ECCV 2026
